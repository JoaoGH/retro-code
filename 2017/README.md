# 2017

Este diretório contém os códigos e estruturas desenvolvidos durante o ano de 2017, marcando a transição para conceitos de Programação Orientada a Objetos (POO), construção de interfaces gráficas complexas e persistência de dados relacional.

## Linguagens e Paradigmas

Aqui os estudos abandonaram o modelo puramente procedural e focaram fortemente no desenvolvimento de aplicações desktop e gerenciamento de banco de dados integrado.

### Programação (Java)

A linguagem Java foi a grande protagonista do ano, introduzindo o aprendizado de arquitetura de componentes visuais, gerenciamento de eventos de interface (como cliques de botões) e tratamento de arquivos locais.

As ferramentas exploradas foram:
- **Java Swing**: Uso de componentes nativos (`JFrame`, `JPanel`, `JTextArea`) para desenhar layouts responsivos e interativos.
- **Java Sound API**: Manipulação de streams de áudio físicos.

Como principal IDE foi usado o [NetBeans](https://www.oracle.com/br/tools/technologies/netbeans-ide.html) para desenvolver os códigos, aproveitando o seu construtor de formulários visual (GUI Builder).

Os códigos fontes podem ser vistos [aqui](./programming/).

### Banco de Dados

Os estudos avançaram para a criação, população e consumo de bancos de dados relacionais em tempo real por meio de aplicações externas utilizando o **MySQL** e o driver **JDBC**.

Os scripts criados podem ser vistos [aqui](./database/).
