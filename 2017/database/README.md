# Banco de Dados - 2017

Aqui ficam listados os scripts desenvolvidos no ano de 2017 para a cadeira de Banco de Dados.

O foco dos estudos deste ano foi a integração de esquemas relacionais com aplicações externas, utilizando o **MySQL** como sistema gerenciador e o **phpMyAdmin** para administração do ambiente local.

- [Tabela Periódica](./2017-XX-XX_tabela-periodica/)
  - Descrição: Script SQL completo para criação de tabelas e carga de dados estruturados, incluindo o armazenamento de imagens convertidas para strings Base64.
