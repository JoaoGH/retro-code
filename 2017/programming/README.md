# Java - 2017

Aqui ficam listados os códigos e sistemas desenvolvidos no ano de 2017 na linguagem Java.

Os estudos deste ano marcaram a transição do paradigma procedural para a **Programação Orientada a Objetos (POO)** e o desenvolvimento de interfaces gráficas complexas (GUI) utilizando a biblioteca **Java Swing** dentro da IDE **NetBeans**.

- [Cálculo de Salário](./2017-02-17_relembrar/)
  - Descrição: Algoritmo utilitário em C++ transicionado para testes de laços de repetição aplicados a regras de abonos progressivos.
- [Reprodução de Voz](./2017-04-27_reproducao-voz/)
  - Descrição: Script prático utilizando a API nativa `javax.sound.sampled` para carregar e reproduzir ficheiros de áudio `.wav`.
- [Gerador de Números Primos](./2017-10-27_numeros-primos/)
  - Descrição: Aplicação desktop em Swing para cálculo iterativo de números primos com exportação e escrita de dados num ficheiro `.txt` local.
- [Tabela Periódica Digital II](./2017-XX-XX_tabela-periodica-2/)
  - Descrição: Sistema interativo em Java Swing interligado via JDBC ao MySQL para renderizar a tabela periódica, carregar fichas técnicas e decodificar imagens em Base64.
